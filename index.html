Weather & News aggregator

A web app that combines two sources of information in one place. Users can check current weather conditions for any city using the OpenWeatherMap API, or enter keywords to get the latest news articles matching their interests, powered by the News API. The news search uses keyword relevancy ranking, so the most closely matching articles appear first.

Built with: Python, SQLite, OpenWeatherMap API, News API.

CS50 Harvard

CS50 Introduction to Python

I completed Harvard's CS50P. Across the course I worked on problem sets covering functions, conditionals, loops, exceptions, file handling, and unit testing. I built programs such as a nutrition lookup tool, a file extension handler, and a date formatter, validating each one against CS50's automated checker.

For my final project, I built an automated listing formatter for selling second hand clothing on Vinted, which let me apply what I'd learned to a real problem that I encounter in my life. It works by taking in user input on an item or clothing they want to sell and creates a csv file containing a ready to go title and description including hashtags for the user to then use when listing their item.
